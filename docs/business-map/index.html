Bản đồ nghiệp vụ: plugin sdlc

Cách đọc bản đồ

Mỗi luồng là một phần nghiệp vụ, vẽ bằng ô và mũi tên; chữ trên mũi tên cho biết khi nào đi theo nhánh đó. Viền của ô cho biết bản đồ chắc chắn đến đâu về bước đó, dấu ⚠ đánh dấu bước còn câu hỏi mở. Bấm vào một ô để nhảy tới bước đó bên dưới, nơi ghi rõ từng nguồn.

  • Đã chạy thử, đúng
  • Đã thấy trong code
  • Tài liệu ghi vậy
  • Đoán, chưa xác nhận
Dựng từ commit fccb53e

Agent sửa một file

Mỗi lần agent sửa file trong repo đã bật sdlc, plugin chặn những sửa đổi sai luật trước khi chúng xảy ra và kiểm tra lại sau khi sửa. Kết quả cuối: lượt làm việc chỉ kết thúc khi lệnh verify của repo chạy xanh.

Ai thực hiện: Agent viết code (Claude, Codex…)
